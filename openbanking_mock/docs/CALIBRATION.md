## Assumptions with no source

| choice | detail |
|---|---|
| Multi-banking | 30% of customers also hold a second bank, 3% a third; the second/third bank is drawn with the same weights as the primary bank |
| Statement narratives | Georgian/English wording of statement lines; portals with real samples were not browsed |
| Merchants, MCC, ticket sizes | merchant lists, ticket-size distributions and MCC per category |
| Salary pay-day mix and holiday shift | day-of-month distribution; a salary due on a weekend or holiday is paid the previous business day |
| Remittance currency and operators | corridor shares are NBG Aug-2026; the currency each lands in and the provider lists are assumed |
| ISO 20022 code assignment | which internal transaction kind maps to which bankTransactionCode / purposeCode (every code itself is validated against the official ISO table); neither TBC nor BoG publishes the codes it really uses |
| TBC proprietary codes | GMI (credit) / GMB (debit) are published only on example transfers and card transactions; here they appear on transfers and card entries only |
| IBAN internal structure | GE + check + bank code + 16 digits is standard; the digit layout inside the 16 digits is random with a product digit |
| Optional-field population | which optional schema fields TBC/BoG really fill in production |
| Loan default prevalence | taken from the supplied df labels, far above real retail NPL, by design |
